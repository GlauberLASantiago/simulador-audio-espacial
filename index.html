Progressão didática

1. Mono

O sinal é percebido no centro, sem deslocamento lateral. Serve como ponto de partida para compreender a ausência de imagem espacial entre canais.

2. Estéreo

O som pode ser deslocado entre esquerda e direita. Surge a imagem estereofônica, mas ainda sem uma representação completa de altura e profundidade.

3. Tridimensional

A fonte passa a ser descrita por azimute, elevação e distância. Essa lógica prepara a compreensão de sistemas de representação espacial como Ambisonics.

Nota técnica: o que esta aplicação faz e o que ela não faz

Esta aplicação realiza uma simulação binaural tridimensional, mas não implementa uma cadeia Ambisonics completa.

O modo tridimensional utiliza o recurso PannerNode da Web Audio API, com processamento HRTF. Isso permite posicionar uma fonte virtual em torno do ouvinte e gerar uma saída estéreo para fones, simulando direção, elevação e distância.

Uma implementação Ambisonics completa exigiria etapas adicionais:

  • codificar a fonte em componentes baseados em harmônicos esféricos;
  • definir ordem, ordenação e normalização, como ACN/SN3D;
  • processar vários canais simultaneamente;
  • aplicar uma matriz de decodificação para alto-falantes ou filtros binaurais específicos;
  • utilizar conjuntos de HRTFs ou arquivos SOFA adequados à decodificação binaural;
  • garantir compatibilidade entre codificador, processadores e decodificador.

Por que essa limitação existe? A Web Audio API oferece espacialização binaural pronta para fontes pontuais, mas não fornece nativamente um codificador e um decodificador Ambisonics completos. Para isso, seria necessário incorporar uma biblioteca especializada ou desenvolver processamento digital próprio, normalmente com Web Audio Worklets, matrizes multicanais e filtros de convolução.

Portanto, o app é adequado para ensinar a passagem conceitual do mono ao estéreo e à espacialização tridimensional. Ele introduz a lógica espacial que ajuda a compreender Ambisonics, mas não deve ser apresentado como um processador Ambisonics profissional.
